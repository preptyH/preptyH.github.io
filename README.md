# preptyH.github.io

Kişisel portfolyo. Statik HTML/CSS + GSAP (ScrollTrigger); kütüphaneler `vendor/` altında kendi sunucumdan servis edilir.

Yayın: https://preptyh.github.io

- İmlece tepki veren dev isim (Archivo genişlik/kalınlık ekseni), kaydırdıkça netleşen vakalar
- Tıklanabilir ajan akış diyagramı, tarayıcıda çalışan fatura denetimi demosu
- `prefers-reduced-motion` açıkken animasyonlar kapalı

Yerelde: `python -m http.server`
