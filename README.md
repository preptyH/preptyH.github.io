# preptyH.github.io

Kişisel portfolyo sitesi — statik HTML/CSS/JS, framework yok.

Yayın: https://preptyh.github.io

- Açık/karanlık tema (sistem tercihi + elle geçiş, localStorage)
- Proje filtresi, hafif görünme animasyonları (`prefers-reduced-motion` destekli)
- Mobil uyumlu, WCAG AA kontrast

Yerelde çalıştırma: `python -m http.server` ve http://localhost:8000
